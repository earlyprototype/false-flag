── THE PASSPHRASE ── START HERE

If you were sent a passphrase, type it here and play. That is the whole of it. This copy of the page carries an OpenRouter key, encrypted; the passphrase unlocks it in your browser and the advisors come alive — they read the paragraph you actually wrote, argue with it, refuse it, point out the thing you forgot. You need no account and no key of your own.

Without the passphrase the encrypted blob is useless, to you and to everyone else who reads this page. You would be spending someone else's money. There is a spend limit on the key, so there is a floor under what this can cost them, but play as if the bill were yours. Do not pass the passphrase on: it is the only thing standing between that key and everyone on the internet.

Locked.

The key is decrypted into memory and dies with this tab. It is not written to this browser's storage and there is deliberately no “remember it” option here — remembering a key that is not yours defeats the point of locking it up. If the key is ever revoked or reaches its spend limit, the page will say so in plain words rather than pretending.

── YOUR OPENROUTER KEY ── START HERE

The advisors need a language model behind them, and that means a key: with one they read the paragraph you actually wrote, argue with it, refuse it, point out the thing you forgot. FALSE FLAG talks to OpenRouter: you paste the key here, your browser sends it straight to OpenRouter, and it goes nowhere else. There is no server behind this page.

Read this before you paste a key. A key typed into a web page is only as safe as the page. If anyone ever manages to get their own JavaScript running here — a cross-site scripting hole in this page, a browser extension, a tampered copy of the site — they can read your key and spend your money. That risk is real and it is not one this page can engineer away. So: use a key with a spend limit set on it, make it a key you use for nothing else, and revoke it when you are done. OpenRouter lets you cap and delete keys from the same page you create them on.
