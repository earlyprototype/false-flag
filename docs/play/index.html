You are the Prime Minister of the United Kingdom, and COBRA is waiting. There is no menu of options. You type what you would actually do, in your own words, and the room answers.

── BEFORE YOU BEGIN ── ABOUT THE API KEY

You can play right now with no key at all. Press PLAY WITHOUT A KEY and the engine runs: turns resolve, the briefings arrive, the metrics move, the campaign reaches an ending. It is the whole shape of the game, and it costs nothing. What it cannot do is have the advisors read what you wrote — with no model behind them their replies come from a deterministic offline stand-in, and you get the same words whatever you type.

To have advisors that actually reason about your paragraph — argue with it, refuse it, point out the thing you forgot — the game needs a language model, and that means a key. FALSE FLAG talks to OpenRouter. You paste the key here, your browser sends it straight to OpenRouter, and it is never sent anywhere else. There is no server behind this page.

Read this before you paste a key. A key typed into a web page is only as safe as the page. If anyone ever manages to get their own JavaScript running here — a cross-site scripting hole in this page, a browser extension, a tampered copy of the site — they can read your key and spend your money. That risk is real and it is not one this page can engineer away. So: use a key with a spend limit set on it, make it a key you use for nothing else, and revoke it when you are done. OpenRouter lets you cap and delete keys from the same page you create them on.

No key set — the advisors will use the offline stand-in.

── OR: PLAY ON THE OWNER'S KEY ── PASSPHRASE REQUIRED

This copy of the page carries the owner's OpenRouter key, encrypted. If you were sent a passphrase, type it here and the advisors come alive without you needing a key of your own. Without the passphrase the encrypted blob is useless, to you and to everyone else who reads this page.

You would be spending someone else's money. They have put a credit limit on the key, so there is a floor under what this can cost them, but play as if the bill were yours. Do not pass the passphrase on: it is the only thing standing between that key and everyone on the internet.

Locked.

The key is decrypted into memory and dies with this tab. It is not written to this browser's storage and there is deliberately no “remember it” option here — remembering a key that is not yours defeats the point of locking it up.

── CAMPAIGN SETUP

Nothing on this page is sent to a server owned by this project. The engine runs inside your browser; if you set a key, the only outbound requests are from your browser to OpenRouter.
