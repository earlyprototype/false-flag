Method

Six auditors mapped one call group each against the source. Six reviewers were instructed to refute rather than confirm, to trace every claimed input from its state object to the f-string that interpolates it, and to default to REFUTED where the code did not settle the question. Reviewer corrections have been applied throughout; line references are the corrected ones. Measurements against saves/parked_campaign4_borrowed_faces.json (1,853 transcript lines, 729,186 characters, 17 completed turns).

01Call inventory

Discussion phase

Advisor Q&A

builder llm/prompts.py:82 · dispatch agents/conversation.py:211 · context ADVISOR_QA → PRO · ≥1 per question; 6 for /advise · sequential

Lets the player interrogate a named cabinet advisor during discussion and receive an in-character, domain-specific answer before committing. One call fires per matched advisor, so a question hitting two keyword sets fires two calls.

Receives

  • Shared dossier (windowed transcript, metrics ×3, secret truth)
  • Advisor role, knowledge domains, key concerns
  • Full scenario constraints, UK order of battle, ammunition stockpiles — all unbounded str() of the dicts
  • The player's question verbatim, uncapped

Does not receive

  • Per-country faction stances
  • Event ledger
  • world.recent_injects

Changes

  • Appends "{role}: {response}" to the campaign transcript, widening every later prompt
  • Screen render; persisted to save
  • No metric, flag or narrative state. Answers are never adjudicated.

Narrator bridge

builder llm/prompts.py:558 · dispatch engine/narrator.py:36 · context none → driver default · 0–1 per turn · sequential

Two to three sentences of atmosphere at the top of a turn, so the jump from last turn's decision to the new event reads as elapsed time.

Receives

  • Turn, phase, casualty counts, active flags
  • Metrics as prose bands only — not the raw values
  • Last 20 transcript elements, a bare literal with no character bound
  • Title of the inject about to be shown

Requested but not honoured

  • system_instruction, temperature=0.7 and max_tokens=150 are passed but ignored on the gemini, mock and offline drivers — the length cap is not enforced

Changes

  • Appends [Narrator] … to the transcript
  • Feeds the inject generator's story digest, which treats [Narrator] lines as notable events
  • No state mutation

Decision phase

Decision interpretation

builder llm/prompts.py:174 · dispatch agents/conversation.py:244 · context DECISION_INTERPRETATION → FLASH · 1 per submission · sequential

Turns the typed order into a structured operational summary: intent, forces, resources, timeline, feasibility.

Receives

  • Shared dossier
  • UK order of battle, stockpiles, constraints — untruncated
  • The player's raw decision text, not truncated and not escaped

Does not receive

  • This turn's decision line — appended to the local transcript only after the call

Changes

  • Transcript lines, and thus all later prompts
  • The OPERATIONAL ORDER panel shown before confirmation
  • The pushback prompt in the same turn
  • Metric deltas indirectly, via the quality-assessment prompt

The five requested output labels are never parsed. Nothing validates INTERPRETATION / FORCES / RESOURCES / TIMELINE / FEASIBILITY; the string is consumed whole.

Advisor pushback

builder llm/prompts.py:244 · dispatch agents/conversation.py:272 · context ADVISOR_PUSHBACK → FLASH · 1 per submission · sequential

A last in-fiction warning before adjudication, and the gate that lets the player amend.

Receives

  • Shared dossier
  • The decision text and the interpretation from the previous call, both untruncated
  • Advisor roster with pushback triggers; Russian characters filtered out by a note key

Changes

  • Transcript lines
  • The ADVISOR CONCERNS panel and the proceed / re-type / return-to-discussion gate
  • API concerns_list, where every entry is given the canned recommendation "Consider revising your approach."
  • Nothing mechanical — no metric, flag, trust value or ledger entry is written from pushback anywhere

Critical omissions scan ×5

builder llm/prompts.py:462 · dispatch agents/conversation.py:382 → llm/fanout.py:67 · context CRITICAL_OMISSIONS → PRO · 5 per submission · one parallel group

Five ministers independently scan the order for a catastrophic gap — no NATO coordination, no legal authority, no public statement, no ally consultation, no logistics — and each offers at most one concern and one fix.

Receives

  • Shared dossier
  • Advisor role name, twice
  • A hardcoded one-line remit blurb keyed on character id
  • RECENT EVENTS: inject titles only, double-windowed to 5
  • The raw decision text, uncapped

Does not receive

  • The interpretation — passed into the function, never reaches the prompt
  • The pushback the same advisors just produced
  • Advisor personality — read from config, never interpolated
  • This turn's decision-phase working transcript
  • Event ledger; world.posture, spatial_state, diplomatic_relationships

Changes

  • Rewrites the player's decision text when a recommendation is applied, then re-runs interpretation, pushback and this scan against the amended order
  • Transcript lines; API concerns payload
  • No direct metric, flag or trust mutation

Briefing phase

Inject generation

builder llm/prompts.py:334 · dispatch llm/inject_generator.py:71 · context INJECT_GENERATION → PRO · 0–1 per turn · sequential

Once the authored turn files run out, this single call invents the event the player wakes up to: headline, two-to-three paragraph brief, and the metric effect it carries.

Receives

  • Turn number, three raw metrics
  • Secret narrative truth (global only)
  • STORY SO FAR digest — mechanically derived, not an LLM call: last 3 event-ish lines, each cut to 100 characters, and only when the transcript exceeds 10 lines
  • EVENTS ALREADY PLAYED ledger — entry count unbounded, titles cut to 60 chars, notes to 90
  • LAST TURN window — 400 lines max, char-bounded, sliced back to the last TURN N header
  • UK and Russian objectives, escalation patterns, scenario menu (filtered by ledger)

Does not receive

  • The GAME HISTORY block. Verified empirically: the string "GAME HISTORY" does not appear in the generated prompt. Its only view of turns 1–16 is the ledger plus the digest.
  • Per-country faction stances

Changes

  • The event shown to the player; its parsed effects apply metric deltas
  • Writes a ledger entry, whose disposition is set later at adjudication
  • Appends the inject title to world.recent_injects

Adjudication phase

Action quality assessment

builder engine/narrative_adjudication.py:223 · context none → driver default · 1 per turn · sequential

Grades the decision on a five-word scale and proposes metric effects. This is the call that moves the numbers.

Changes

  • Quality word, whitelist-validated, else defaults to "adequate"
  • Multiplier clamped to [0.5, 2.5]; if it parses to exactly 1.0 the quality→multiplier table overrides it
  • suggested_effects → hidden metrics, via 60/40 merge with actor effects on the actor path
  • Advisor trust shifts — narrative path only; never called on the actor path
  • Reasoning is leak-scrubbed, then displayed and saved

Does not receive

  • Event ledger, world flags, posture, spatial state, recent injects, diplomatic relationships, play mode

Parser hazard: the effects branch fires on any line containing a colon and the substring escalation / alliance / stability, so continuation lines of the reasoning paragraph can be absorbed as effects.

Advisor reactions ×4

builder engine/narrative_adjudication.py:597 · context none → driver default · 1–4 per turn · one parallel group

Receives

  • Hidden metrics (post-effect), casualties, active crises
  • Relationship roster for all five characters
  • The raw action text and the one-word quality grade
  • A tone adjective selected from the quality word

Does not receive

  • The dossier, transcript, secret truth, ledger
  • The applied metric deltas, the adjudicator's reasoning, the interpretation
  • Sibling advisors' reactions, or the actor responses generated earlier in the same turn

LLMContext.CHARACTER_RESPONSE is defined and mapped to FLASH but is dead for this call: generate_group is invoked positionally, so context keeps its None default. Output mutates nothing — pure flavour text.

Situation summary refresh

builder engine/narrative_adjudication.py:675 · context none → driver default · 1 per turn · sequential, last

Rewrites the standing two-to-three sentence brief. Receives post-effect metrics, crises, the relationship roster and the raw decision.

The output reaches no prompt. It overwrites NarrativeState.situation_summary, which is read only by emergent-mode display and three CLI render sites. It is not in to_llm_context(), and the inject prompt's STORY SO FAR block uses a different, mechanically derived string. It is not appended to the save transcript either. It also does not receive the previous summary it replaces.

State actor responses ×3

builder engine/actor_simulation.py:24 · context none — no STATE_ACTOR member exists · 0–3 per turn · one parallel group

Each relevant foreign government answers the decision with a public line, a private assessment, a trust delta, and a support verdict.

Receives

  • Full actor dossier: motivations, hidden agendas, redlines, dependencies, capability / leverage / influence scores
  • World context: hidden metrics, casualties, last 3 recent events, active crises, in-fiction clock
  • Secret narrative truth (global)
  • Every UK advisor's name, relationship label and trust score
  • The raw UK decision, uncapped

Does not receive

  • The interpretation, the transcript, world metrics/flags/phase
  • The actor's own public_commitments, recent_actions, trust_trajectory, last_contacted
  • Per-country faction stances, the ledger, sibling actors' replies

Changes

  • Trust delta clamped to ±20 → bilateral relationship, and domestic stability ±2/−3
  • Support verdict weighted by diplomatic influence → alliance cohesion and escalation risk, plus a consensus bonus
  • Merged 60/40 with quality effects into hidden metrics; can trip crisis thresholds

02Shared context composition

Assembled by build_shared_context_prefix (llm/context_builder.py:285-355), ordered slowest-changing first so a prefix cache can match through it. On the measured campaign it renders to ≈307,000 characters, 99.4% identical between the eight calls that use it.

Three of its blocks are the same three metrics rendered three ways: raw values out of 100, prose bands, and KEY INTELLIGENCE FLAGS. The flags are five booleans computed by thresholding those metrics (engine/flags.py:15-35) and the dict is replaced rather than accumulated each turn (engine/flags.py:38-40), so the third rendering carries no information the first two do not.

Per-country FactionStance data — secret motive, public posture, economic leverage, intelligence-sharing level — never reaches this block: to_llm_context() is called with no country argument (llm/context_builder.py:323), skipping models/narrative.py:46-67 for all eight calls.

05Findings

F-1 · Defect · guard silently removed

An empty ledger removes the do-not-restage rule as well as the data

Continuity rule 8 is appended only under if event_ledger:. An empty list is falsy, so a campaign with no ledger entries receives neither the EVENTS ALREADY PLAYED block nor the instruction not to restage resolved events.

This state is reachable two ways: a fresh campaign before the first event is recorded, and any save written before the field existed — persistence rebuilds NarrativeState with the default_factory=list, so the ledger returns empty. The failure mode is unguarded rather than degraded, and is the condition under which the repeated-event bug the ledger was built to fix can recur.

llm/prompts.py:422 · models/narrative_state.py:88 · engine/persistence.py:134

F-2 · Defect · silent data loss

The interpretation is passed to the omissions check and never reaches the prompt

check_critical_omissions takes interpretation as a parameter and build_critical_omissions_prompt never interpolates it. Five advisors judging whether the decision omitted something catastrophic are working from the raw typed text, not the structured reading of it that was produced moments earlier for exactly that purpose. Advisor personality is read from config on the same path and likewise never interpolated.

engine/sim_loop.py:569 · agents/conversation.py:376-381 · llm/prompts.py:462-553, :491

F-3 · Configuration inert

Eight of twelve call families bypass the model configuration

The narrator, action quality assessment, advisor reactions, situation summary and state actors pass no context=, so the router leaves model_name as None and the driver default is used. LLMContext.CHARACTER_RESPONSE is defined and mapped to FLASH but has zero live call sites — generate_group is invoked positionally at the reactions call site, so context keeps its default. There is no STATE_ACTOR member at all.

Consequence: the per-context tier table and the /llm settings menu govern the discussion, decision, inject and diplomacy families only. The entire adjudication half of a turn is outside their reach.

llm/router.py:231-234, :331-335 · llm/model_config.py:10-38 · engine/narrative_adjudication.py:545 · engine/actor_simulation.py:131

F-4 · Coverage gap

Seven call families do not use the shared dossier

Inject generation, the narrator, all three adjudication calls, the actor group and both diplomacy calls each assemble their own header. They are therefore not cacheable against the eight that do share one, and they diverge in what they know: the transcript reaches none of them, and the inject generator — the only recipient of the ledger — receives no history block at all. No prompt in the game holds both the campaign history and the ledger.

llm/context_builder.py:285-355 · llm/context_builder.py:391-439

F-5 · Unbounded input

Two context builders apply no size limit

get_diplomatic_context applies no bound of any kind to its filtered transcript. The narrator takes the last 20 transcript elements with no character cap, where a single element can be an unwrapped paragraph. Both share the shape of the overrun already corrected in the advisor window, where 400 long lines reached 792,572 characters against a 320,000 budget.

Separately, the player's decision text is interpolated untruncated and unescaped into four prompts, and the scenario uk_forces, stockpiles and constraints dicts are stringified whole into three.

llm/context_builder.py:441-512 · llm/prompts.py:587 · llm/prompts.py:202, :277, :501

F-6 · Parser hazard

The effects parser can absorb prose from the reasoning paragraph

The effects branch in the quality-assessment parser fires on any line containing a colon and the substring escalation, alliance or stability. A continuation line of the REASONING paragraph matching that shape is read as a metric effect. Related: a multiplier that parses to exactly 1.0, or is missing, is overridden by the quality→multiplier table.

engine/narrative_adjudication.py:374-381, :383-399

F-7 · Redundancy

The three metrics appear three times in every dossier-carrying prompt

Raw values out of 100, prose bands, and KEY INTELLIGENCE FLAGS. The flags are five booleans thresholded from the same three metrics, and the dict is replaced rather than accumulated each turn, so the third rendering adds nothing the first two do not carry.

llm/context_builder.py:335-341, :351-352 · engine/flags.py:15-40

F-8 · Output not honoured

Requested output constraints are dropped on some drivers

The narrator passes system_instruction, temperature and max_tokens=150; none is honoured on the gemini, mock or offline drivers, so the length cap on the bridge text is not enforced. The decision-interpretation prompt specifies five labelled output fields and nothing in the codebase parses or validates them.

engine/narrator.py:39-41 · llm/prompts.py:230-235

F-9 · Asymmetric adjudication paths

Advisor trust updates only on one of the two adjudication paths

_update_character_attitudes is called on the narrative path and never on the actor-simulation path, so advisor trust shifts on decision quality in one mode and not the other. The two paths also compute base effects differently — LLM-suggested effects on one, a keyword heuristic merged 60/40 with actor effects on the other.

engine/narrative_adjudication.py:788, :928-943, :865-876

06Budget context

MAX_ADVISOR_TRANSCRIPT_CHARS is documented as leaving headroom inside a 128,000-token context window. The measured campaign is 729,186 characters, approximately 182,000 tokens; a full advisor prompt built from the windowed block measures 314,695 characters, approximately 78,700 tokens.

Prefix-cache overlap between the eight dossier-carrying calls is 99.4% as measured by byte comparison of emitted prompts. Whether a provider reports a cache hit on a prefix of that size has not been confirmed against a live endpoint.
